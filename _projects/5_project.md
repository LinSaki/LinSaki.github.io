This project is a modern, responsive web application developed for a small company affiliated with the University of Toronto. Built using React.js and styled with Tailwind CSS, the site is designed to deliver a clean user interface and smooth user experience. My role involves implementing dynamic front-end features, ensuring mobile responsiveness, and aligning the design with the company’s branding guidelines. The project is currently in development, with ongoing collaboration and feedback from the client.
