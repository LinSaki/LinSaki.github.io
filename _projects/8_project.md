Created a fast-paced bullet hell game using WPF, the .NET Framework, and C#. The player controls a character inspired by _Enter the Gungeon_, shooting at bouncing squares and circles that move randomly across the screen. Scoring is tied to weapon progression—every 5 points increases the number of bullets fired. The game ends if the player collides with any of the shapes. One of my first interactive games, focused on learning game logic, collision detection, and UI in WPF.
